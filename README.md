## 🧠 O que estou desenvolvendo

### 💠 J.A.D.E.
**Just Another Developer's Entity**

Meu projeto de assistente pessoal com IA, criado para ir além de simplesmente conversar com o usuário.

- 📱 Desenvolvimento Android nativo com **Kotlin + Jetpack Compose**
- 🤖 Conversas utilizando IA
- 🎙️ Interação por voz
- ⚡ Ações integradas ao Android
- 🔄 Rotinas e automações
- 🧠 Preferências e informações persistentes do usuário
- 🔊 Sistemas personalizados de voz
- 🖥️ Experimentos com IA local e versão desktop

O objetivo é simples:

**Criar um assistente que realmente faça parte do dispositivo.**
